Conexões reaproveitadas

Uma conexão mestre aberta deixa as próximas conexões instantâneas. Esta aula mostra como ligar e controlar.

Você vai aprender
  • Ligar o ControlMaster no config.
  • Ver a diferença de tempo.
  • Conferir e fechar a mestre com -O.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

A ideia: uma conexão, muitas sessões

Cada ssh faz a negociação de criptografia e a autenticação do zero. Com ControlMaster, a primeira conexão vira uma “mestre” que fica aberta, e as próximas passam por dentro dela, sem negociar de novo. Fica bem mais rápido, ótimo para scripts que rodam vários comandos seguidos.

1. Ligar no config

Host servidor
    ControlMaster auto
    ControlPath ~/.ssh/cm-%r@%h:%p
    ControlPersist 10m
ControlMaster auto
usa uma mestre se existir; se não, cria.
ControlPath
onde fica o “soquete” da mestre (%r usuário, %h host, %p porta).
ControlPersist 10m
mantém a mestre aberta 10 minutos depois da última sessão.

Na coleta, a Ana pôs o bloco no começo do config (lembre: o primeiro valor vence) e mediu o tempo de duas conexões:

$ printf 'Host servidor\n    ControlMaster auto\n    ControlPath ~/.ssh/cm-%%r@%%h:%%p\n    ControlPersist 10m\n' | cat - ~/.ssh/config > /tmp/config.novo && mv /tmp/config.novo ~/.ssh/config
$ time ssh servidor true

real	0m0,090s
user	0m0,007s
sys	0m0,004s
$ time ssh servidor true

real	0m0,010s
user	0m0,000s
sys	0m0,007s
$

A segunda foi mais rápida: já havia uma mestre aberta. Os números exatos variam; numa rede de verdade, com o servidor longe, a diferença é bem maior.

2. Controlar a mestre: -O

$ printf 'Host servidor\n    ControlMaster auto\n    ControlPath ~/.ssh/cm-%%r@%%h:%%p\n    ControlPersist 10m\n' | cat - ~/.ssh/config > /tmp/config.novo && mv /tmp/config.novo ~/.ssh/config
$ ssh servidor true
$ ls ~/.ssh
cm-lab@192.168.0.20:22	config	id_ed25519  id_ed25519.pub  known_hosts   « o soquete da mestre
$ ssh -O check servidor
Master running (pid=51)   « a mestre está aberta
$ ssh -O exit servidor
Exit request sent.   « pedido para fechar
$ ssh -O check servidor
Control socket connect(/home/ana/.ssh/cm-lab@192.168.0.20:22): No such file or directory
$

Quando dá errado

Pasta do ControlPath não existe

Se o ControlPath apontar para uma pasta que não existe, a mestre não consegue criar o soquete:

$ ssh -o ControlMaster=auto -o ControlPath='~/.ssh/naoexiste/cm-%r@%h:%p' servidor true
unix_listener: cannot bind to path /home/ana/.ssh/naoexiste/cm-lab@192.168.0.20:22.gZ8N9MWnCcFQZyMI: No such file or directory
$

Crie a pasta antes (mkdir -p ~/.ssh/naoexiste) ou use um caminho que exista.

Resumo

  • A mestre evita negociar de novo.
  • O ControlPath precisa de uma pasta que exista.
  • -O exit fecha a mestre.
