Pipes pela rede

O cano do Bash atravessa a rede com o ssh. Esta aula mostra receitas clássicas com tar e diff.

Você vai aprender
  • Enviar uma pasta com tar | ssh.
  • Trazer um backup com ssh … >.
  • Comparar arquivos com diff <(ssh …).

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

A ideia: o cano atravessa a rede

O ssh liga a entrada e a saída do comando remoto às do notebook. Então dá para usar o | através da rede: o que um programa escreve no notebook chega como entrada de outro programa no servidor, e vice-versa. Sem arquivo temporário.

1. Enviar uma pasta compactada

O tar czf - compacta a pasta e escreve no cano (o - é a saída padrão). No servidor, o tar xzf - lê do cano e extrai:

$ tar czf - projeto | ssh lab@servidor 'mkdir -p backup && tar xzf - -C backup'
$ ssh lab@servidor 'ls -R backup'
backup:
projeto

backup/projeto:
estilo.css
img
index.html
README.md

backup/projeto/img:
logo.png
$

2. Trazer um backup do servidor

$ ssh lab@servidor 'tar czf - site relatorio.txt' > backup-servidor.tar.gz
$ tar tzf backup-servidor.tar.gz
site/
site/index.html
relatorio.txt
$ ls -l backup-servidor.tar.gz
-rw-r--r-- 1 ana ana 297 nov 21 12:02 backup-servidor.tar.gz
$

3. Comparar um arquivo local com o remoto

O <(…) do Bash faz a saída de um comando parecer um arquivo. Com ele, o diff compara o relatório do servidor com uma cópia local alterada:

$ diff <(ssh lab@servidor cat relatorio.txt) relatorio-local.txt
2c2
< vendas: 42   « no servidor
---
> vendas: 45   « no notebook
$

Quando dá errado

Faltou o “-” do tar

Sem o -, o tar czf projeto entende projeto como o nome do arquivo a criar, e não tem nada para pôr nele:

$ tar czf projeto | ssh lab@servidor 'tar tzf -'
tar: Cowardly refusing to create an empty archive
Try 'tar --help' or 'tar --usage' for more information.

gzip: stdin: unexpected end of file
tar: Child returned status 1
tar: Error is not recoverable: exiting now
$

O f - é o que manda o tar escrever no cano: tar czf - projeto.

Resumo

  • O - do tar é o cano.
  • O > fora das aspas grava no notebook.
  • <(…) vira um arquivo para o diff.
