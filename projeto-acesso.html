Projeto: acesso seguro

O roteiro completo de um servidor novo, em quatro passos seguidos.

Você vai aprender
  • Juntar chave, config e sshd.
  • Fazer na ordem certa.
  • Provar o resultado.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

O projeto

Do zero, num servidor novo: criar a chave, levar para o servidor, dar um apelido, desligar a senha e provar que só a chave entra. É o roteiro de todo servidor que você for ganhar. As caixas seguem uma a outra, sem voltar o laboratório ao começo.

1. A chave e o servidor

$ ssh-keygen -q -t ed25519 -N '' -f ~/.ssh/id_ed25519
$ ssh-copy-id lab@servidor

Aqui a chave ficou sem frase para a caixa andar sozinha. No seu notebook, ponha uma frase e use o ssh-agent.

2. O apelido

$ printf 'Host srv\n    HostName servidor\n    User lab\n' >> ~/.ssh/config
$ chmod 600 ~/.ssh/config
$ ssh srv hostname
servidor   « pelo apelido, sem senha
$

3. Fechando a senha, no servidor

$ echo 'PasswordAuthentication no' | sudo tee /etc/ssh/sshd_config.d/10-sem-senha.conf
PasswordAuthentication no
$ sudo sshd -t && sudo kill -HUP "$(cat /run/sshd.pid)"
$

4. A prova

$ ssh -o PubkeyAuthentication=no srv
lab@servidor: Permission denied (publickey).   « sem chave, nada
$ ssh srv 'whoami; hostname'
lab   « com a chave, tudo
servidor
$

Quando dá errado

Desligou a senha antes da chave

Se a ordem se inverte, o servidor tranca você do lado de fora e o ssh-copy-id já não consegue entrar:

$ ssh-keygen -q -t ed25519 -N '' -f ~/.ssh/id_ed25519
$ ssh-copy-id lab@servidor
/usr/bin/ssh-copy-id: INFO: Source of key(s) to be installed: "/home/ana/.ssh/id_ed25519.pub"
/usr/bin/ssh-copy-id: INFO: attempting to log in with the new key(s), to filter out any that are already installed
/usr/bin/ssh-copy-id: INFO: 1 key(s) remain to be installed -- if you are prompted now it is to install the new keys
lab@servidor: Permission denied (publickey).
$

Sempre: chave primeiro, teste, e só então a senha sai.
