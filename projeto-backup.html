Projeto: backup

Um backup de verdade, com o rsync, o config e um script de duas linhas.

Você vai aprender
  • Fazer e atualizar um backup.
  • Recuperar um arquivo.
  • Guardar num script.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

O projeto

Guardar a pasta projeto do notebook no servidor, atualizar só o que mudou, recuperar um arquivo apagado e deixar tudo num script. Usa o apelido servidor do ~/.ssh/config e o rsync.

1. A primeira cópia

$ rsync -a projeto/ servidor:backup/
$ ssh servidor 'ls -R backup'
backup:
estilo.css
img
index.html
README.md

backup/img:
logo.png
$

2. Só o que mudou

$ echo '<!-- versão 2 -->' >> projeto/index.html
$ rsync -av projeto/ servidor:backup/
sending incremental file list
index.html   « só este arquivo viajou

sent 263 bytes  received 42 bytes  610,00 bytes/sec
total size is 2.137  speedup is 7,01
$

3. Recuperando um arquivo

$ rm projeto/estilo.css
$ rsync -av servidor:backup/estilo.css projeto/
receiving incremental file list
estilo.css   « voltou do servidor

sent 43 bytes  received 129 bytes  344,00 bytes/sec
total size is 22  speedup is 0,13
$ ls projeto
estilo.css  img  index.html  README.md
$

4. Um script

$ printf '#!/bin/sh\nrsync -a --delete ~/projeto/ servidor:backup/ && echo backup ok\n' > backup.sh
$ chmod +x backup.sh
$ ./backup.sh
backup ok   « o script rodou
$ cat backup.sh
#!/bin/sh
rsync -a --delete ~/projeto/ servidor:backup/ && echo backup ok
$

Para rodar sozinho todo dia às 20h, o crontab -e recebe uma linha como 0 20 * * * $HOME/backup.sh. Como a chave não pede nada (ou o agente está carregado), o cron consegue conectar.

--delete

Com --delete, o que você apagar no notebook some também do backup na próxima vez. Para guardar versões, use uma pasta por dia, como backup/$(date +%F)/.

Quando dá errado

Esqueceu a barra

Sem a barra no fim de projeto/, o rsync cria uma pasta projeto dentro do destino, em vez de copiar o que está nela:

$ rsync -a projeto servidor:backup/
$ ssh servidor 'ls backup'
projeto
$

Com a barra, vai o conteúdo da pasta; sem ela, a pasta inteira. Use sempre --dry-run na dúvida.

Resumo

  • A barra no fim importa.
  • --delete espelha, cuidado.
  • O cron precisa de uma chave que não pergunte.
