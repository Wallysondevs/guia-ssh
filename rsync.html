Sincronizando com rsync

O rsync copia só o que mudou. É a ferramenta de backup e de publicação mais usada com SSH.

Você vai aprender
  • Sincronizar com rsync -av.
  • Ensaiar com --dry-run antes do --delete.
  • Entender a barra no fim da origem.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

A ideia: copiar só o que mudou

O rsync sincroniza pastas: na primeira vez copia tudo; nas seguintes, só o que mudou. Por isso é o preferido para backups e para mandar um site para o servidor. Ele usa o SSH como transporte (e precisa estar instalado nos dois lados: sudo apt install rsync).

3. Ensaiar antes: --dry-run e --delete

O --delete apaga no destino o que não existe mais na origem: o destino fica igual. É poderoso e perigoso. Ensaie com --dry-run (ou -n), que só mostra o que faria. Aqui, a Ana apagou o estilo.css do notebook depois de uma cópia:

$ rsync -av --delete --dry-run projeto/ lab@servidor:projeto/
sending incremental file list
deleting estilo.css   « o que o --delete apaga
./

sent 168 bytes  received 41 bytes  418,00 bytes/sec
total size is 2.096  speedup is 10,03 (DRY RUN)   « ensaio: nada foi apagado ainda
$ ssh lab@servidor 'ls projeto'
estilo.css
img
index.html
README.md
$ rsync -av --delete projeto/ lab@servidor:projeto/
sending incremental file list
deleting estilo.css
./

$
-e: escolher como conectar

O -e passa opções ao ssh, como a porta ou a chave: rsync -av -e 'ssh -p 2222 -i ~/.ssh/servidor_lab' projeto/ lab@servidor:projeto/. Com o config, nem precisa: o apelido já traz tudo.

Quando dá errado

A barra no fim muda tudo

projeto (sem barra) copia a pasta; projeto/ (com barra) copia o conteúdo. Errar isso cria uma pasta dentro da outra:

$ rsync -a projeto lab@servidor:copia1/
$ rsync -a projeto/ lab@servidor:copia2/
$ ssh lab@servidor 'ls copia1 copia2'
copia1:
projeto

copia2:
estilo.css
img
index.html
README.md
$

Na dúvida, use barra nos dois lados (origem/ destino/) e ensaie com -n.
