Apelidos no ~/.ssh/config

O config guarda o usuário, a porta e a chave de cada servidor com um apelido curto.

Você vai aprender
  • Escrever um bloco Host.
  • Conferir a configuração com ssh -G.
  • Usar o apelido no scp e no rsync.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

A ideia: apelidos para os seus servidores

Digitar ssh -i ~/.ssh/chave -p 2222 lab@192.168.0.20 toda vez cansa e dá erro. O arquivo ~/.ssh/config guarda essas opções com um apelido: depois, basta ssh srv. Vale também para scp, sftp e rsync.

Host srv
    HostName 192.168.0.20
    User lab
    Port 22
    IdentityFile ~/.ssh/id_ed25519
  • Host srv: o apelido. As linhas recuadas abaixo valem para ele.
  • HostName: o endereço de verdade (nome ou IP).
  • User, Port, IdentityFile: o usuário, a porta e a chave, como lab@, -p e -i.

1. Criar o arquivo

Você pode editar com nano ~/.ssh/config. Na coleta, a Ana criou o bloco com printf e deixou o arquivo com permissão 600:

$ printf 'Host srv\n    HostName 192.168.0.20\n    User lab\n' >> ~/.ssh/config
$ chmod 600 ~/.ssh/config
$ cat ~/.ssh/config
Host srv
    HostName 192.168.0.20
    User lab
$ ssh srv hostname
servidor
$

2. Ver o que o ssh vai usar: ssh -G

O -G não conecta: mostra a configuração final que o ssh usaria para aquele apelido. É o melhor jeito de conferir o arquivo:

$ ssh -G srv | grep -E '^(hostname|user|port|identityfile) '
user lab   « veio do User
hostname 192.168.0.20   « veio do HostName
port 22   « o padrão, já que não foi dito
identityfile ~/.ssh/id_rsa
identityfile ~/.ssh/id_ecdsa
identityfile ~/.ssh/id_ecdsa_sk
identityfile ~/.ssh/id_ed25519
identityfile ~/.ssh/id_ed25519_sk
identityfile ~/.ssh/id_xmss
$

3. O apelido vale para tudo

$ scp notas.txt srv:
notas.txt                                                         100%   53   135.4KB/s   00:00    
$ ssh srv ls
notas.txt
relatorio.txt
site
$

Quando dá errado

Opção com erro de digitação

Uma opção escrita errado (aqui, HostNme) faz o ssh parar, avisando a linha:

$ printf 'Host srv\n    HostNme 192.168.0.20\n' > ~/.ssh/config
$ ssh srv hostname
/home/ana/.ssh/config: line 2: Bad configuration option: hostnme
/home/ana/.ssh/config: terminating, 1 bad configuration options
$

Corrija a linha indicada. O ssh -G apelido acusa o mesmo erro sem tentar conectar.
