Criando a chave: ssh-keygen

Um comando cria o seu par de chaves. Esta aula mostra as perguntas do ssh-keygen e o que ele grava.

Você vai aprender
  • Gerar uma chave ed25519 com frase.
  • Ver o que foi criado sem abrir a privada.
  • Gerar sem perguntas, com -f e -N.

Todas as saídas desta aula foram colhidas de verdade com o OpenSSH 10.0p2 no Linux (Debian 13, Bash 5.2, pt_BR.UTF-8), no laboratório do guia: o notebook (usuária ana, 192.168.0.10), o servidor (usuário lab, 192.168.0.20) e o interno (192.168.0.130, que só o servidor alcança). Antes de cada caixa o laboratório volta a um estado conhecido. As chaves e as impressões digitais que aparecem são de teste e já foram destruídas.

A ideia: criar o seu par de chaves

O ssh-keygen cria o par. Use o tipo ed25519: é moderno, rápido e tem chaves curtas. O -C põe um comentário (costuma ser usuario@computador) para você saber, lá no servidor, de quem é cada chave.

1. Gerar a chave

A Ana gerou a primeira chave dela. O ssh-keygen fez três perguntas: onde salvar (Enter aceita o padrão), e a frase secreta (passphrase) duas vezes. A frase protege a chave privada: se alguém copiar o arquivo, ainda precisa dela. Como a senha, ela não aparece enquanto você digita.

$ ssh-keygen -t ed25519 -C "ana@notebook"
Generating public/private ed25519 key pair.
Enter file in which to save the key (/home/ana/.ssh/id_ed25519): 
Created directory '/home/ana/.ssh'.   « a pasta ~/.ssh foi criada
Enter passphrase for "/home/ana/.ssh/id_ed25519" (empty for no passphrase): 
Enter same passphrase again: 
Your identification has been saved in /home/ana/.ssh/id_ed25519   « a chave privada
Your public key has been saved in /home/ana/.ssh/id_ed25519.pub   « a chave pública
The key fingerprint is:   « a impressão digital da chave
SHA256:xUkC9WGWYWmEW5x41POy8R+LpD9JB69nFXtnAz34jQk ana@notebook
The key's randomart image is:
+--[ED25519 256]--+
|      .oo*X*     |
|        oOOoo    |
|         ==  oo  |
|        ..  E+.+ |
|        S    *=o=|
|            .o+B*|
|            + =oB|
|           . = +.|
|            ..+  |
+----[SHA256]-----+
$
-t ed25519
o tipo da chave.
-C "ana@notebook"
o comentário que vai no fim da chave pública.

O desenho (randomart) é outra forma de ver o fingerprint: duas chaves diferentes dão desenhos diferentes.

2. O que foi criado

$ ls -l ~/.ssh
total 12
-rw------- 1 ana ana 399 nov 21 12:01 id_ed25519   « privada: permissão 600
-rw-r--r-- 1 ana ana  94 nov 21 12:01 id_ed25519.pub
-rw------- 1 ana ana 568 nov 21 12:01 known_hosts
$ cat ~/.ssh/id_ed25519.pub
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIEhUpv1BK1coguxPjJIpUIlNaF5MdZXnkYskI28ZKD0p ana@notebook
$ ssh-keygen -lf ~/.ssh/id_ed25519.pub
256 SHA256:1wgPtPehvxJHxq1qIDo4s7Eu1nZObhihxhAUBwbUHkU ana@notebook (ED25519)
$ file ~/.ssh/id_ed25519
/home/ana/.ssh/id_ed25519: OpenSSH private key   « o file diz o que é, sem mostrar o conteúdo
$

Para saber o que é um arquivo de chave sem abrir, use file ou ssh-keygen -l. Abrir a privada com cat mostraria o segredo na tela.

3. Escolher o nome e não perguntar nada

Em scripts, ou para ter uma chave por servidor, passe tudo na linha: -f (arquivo), -N (frase; '' = sem frase) e -q (quieto):

$ ssh-keygen -t ed25519 -f ~/.ssh/servidor_lab -N '' -C 'chave do lab' -q
$ ls ~/.ssh
id_ed25519  id_ed25519.pub  known_hosts  servidor_lab  servidor_lab.pub
$ ssh-keygen -t rsa -b 4096 -f ~/.ssh/antiga_rsa -N '' -q
$ ssh-keygen -lf ~/.ssh/antiga_rsa.pub
4096 SHA256:iM01jGkDJflBCc6SCguZGJ7698sKb9lVlvA5Rkn/5T0 ana@notebook (RSA)   « RSA de 4096 bits: o tipo antigo
$
ed25519 ou RSA?

Prefira ed25519. Use RSA (com -b 4096) só se um sistema antigo não aceitar ed25519.

Quando dá errado

A chave já existe

Rodar o ssh-keygen de novo com o mesmo nome pergunta se pode sobrescrever. Responda n: trocar a chave quebra o acesso a todos os servidores onde a antiga está instalada.

$ ssh-keygen -t ed25519
Generating public/private ed25519 key pair.
Enter file in which to save the key (/home/ana/.ssh/id_ed25519): 
/home/ana/.ssh/id_ed25519 already exists.
Overwrite (y/n)? n
$

Para uma chave nova, escolha outro nome com -f.
